## اجرای محلی صفحه‌های گرافیکی

```bash
python3 -m http.server 8000 --bind 0.0.0.0 --directory docs
# سپس باز کنید: http://localhost:8000/
```

هر دو صفحه کاملاً خودکفا هستند (بدون وابستگی به CDN) و به‌صورت آفلاین هم کار می‌کنند؛
کد Mermaid آن‌ها در گیت‌هاب و گیت‌لب به‌صورت خودکار رندر می‌شود.
